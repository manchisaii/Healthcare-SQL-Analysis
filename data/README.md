# Data Source

The dataset used in this project was obtained from Kaggle:

**Hospital Management Dataset**  
Author: Kanak Baghel  
Source: https://www.kaggle.com/datasets/kanakbaghel/hospital-management-dataset

The dataset contains synthetic hospital management data across patients, doctors, appointments, treatments, and billing.

The original dataset is used as the source data for this analysis. The data was cleaned and prepared for PostgreSQL analysis as documented in the SQL project.
